# Eclipse Clock

Un orologio web dedicato alle prossime eclissi solari e lunari.

## Funzioni

- countdown in tempo reale verso la prossima eclissi
- eclissi solari e lunari
- filtri per tipo
- timeline degli eventi
- tre temi: Cosmic, Neon e Minimal
- animazione Sole/Luna
- layout responsive per iPhone, tablet e desktop
- struttura pronta per ampliare il catalogo con altri anni

## Dati astronomici

Le date iniziali sono basate sui cataloghi NASA/GSFC di Fred Espenak. NASA pubblica cataloghi di eclissi solari e lunari che coprono migliaia di anni; il progetto può quindi essere esteso molto oltre il calendario iniziale senza cambiare l'interfaccia.

Fonte NASA: https://eclipse.gsfc.nasa.gov/

Attribuzione: "Eclipse Predictions by Fred Espenak, NASA's GSFC".

## Avvio

È un'applicazione statica: apri `index.html` oppure pubblicala con GitHub Pages.
